# Documentation

[简体中文](../zh-cn/README.md) · [WattSign](../../README.md)

WattSign studies appliance states from household power and controlled voltage/current recordings, and load properties from single-appliance electrical features. These guides explain the data behind each task, the implemented training workflows and what the saved results establish.

| Guide | Contents |
|---|---|
| [Quick start](quickstart.md) | Installation, result browsing and training notebooks |
| [Data](data.md) | Dataset backgrounds, task inputs and labels, layouts and local paths |
| [Methods](methods.md) | Physical inputs, causal models and evaluation protocols |
| [Results](results.md) | Findings, metric interpretation, comparisons and experimental limitations |
| [Runtime and artifacts](runtime.md) | CPU/CUDA/NPU environments, conversion and model files |
| [References and licensing](references.md) | Dataset and method references, component licenses |

Start with [Data](data.md) for the measurement settings, then [Methods](methods.md) for the implementation and [Results](results.md) for the findings. [Quick start](quickstart.md) leads to the three English notebooks and their training entry points.

The [case index](../../results/index.json) links each experiment to its runs and evidence. Reported results include all recorded seeds and folds for the selected configuration.
