# 文档

[English](../en/README.md) · [WattSign](../../README.zh-CN.md)

WattSign 从家庭总表信号、受控电压电流记录和单设备电气特征中研究设备状态与负载属性。这些文档介绍各任务的数据背景、已实现的训练流程，以及已有结果支持的结论。

| 文档 | 内容 |
|---|---|
| [快速开始](quickstart.md) | 安装、结果查询和训练 Notebook |
| [数据](data.md) | 数据集背景、任务输入与标签、数据目录和本地路径 |
| [方法](methods.md) | 物理输入、因果模型和评测协议 |
| [结果](results.md) | 实验发现、指标解读、对照实验和适用范围 |
| [运行环境与成果](runtime.md) | CPU/CUDA/NPU 环境、权重转换和模型文件 |
| [引用与许可](references.md) | 数据与方法来源、各组件许可 |

首次阅读可先从[数据](data.md)了解测量场景，再阅读[方法](methods.md)和[结果](results.md)。[快速开始](quickstart.md)介绍三本英文 Notebook 及其训练入口。

[案例索引](../../results/index.json) 关联各实验的运行记录和结果文件。每个主方案的汇总包含全部已记录 seed 和 fold。
