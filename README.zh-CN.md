# WattSign

[English](README.md) · [简体中文](README.zh-CN.md)

**用电气指纹识别设备活动。**

家庭电表记录的是多台电器叠加后的用电需求。WattSign 研究如何从这条总表信号中识别设备活动，例如判断微波炉是否在其他家庭负载同时用电时工作。项目结合功率测量与电压、电流波形分析，研究设备状态识别和电气负载分类。

这项工作属于**非侵入式负荷监测（NILM）**：从公共供电点的测量中推断单台电器的信息。WattSign 利用功率变化、波形形状和谐波成分构造电气指纹。五个案例分别覆盖家庭微波炉开关状态、受控多设备插座供电状态，以及单设备电阻性负载分类，输出状态概率或负载类别分数。逐设备功率和用电量重建不在这些案例的覆盖范围内。

## 数据与任务

三个公开数据集提供不同的测量场景：

| 数据集 | 记录什么 | 在 WattSign 中的用途 |
|---|---|---|
| [UK-DALE](https://doi.org/10.1038/sdata.2015.7) | 英国家庭用电需求，包含家庭总表和单台电器分表记录 | 用 10 秒或 1 秒总表输入识别微波炉开关状态，设备分表提供参考标签。 |
| [TDHA](https://doi.org/10.1038/s41597-024-03310-3) | 受控家电实验中的高频电压、电流波形及开关事件标注 | 从总表波形识别微波炉状态；另一个任务识别插座供电状态：每条记录有 5 个物理插座，跨记录映射到 11 个共享设备类别通道。 |
| [PLAID](https://doi.org/10.1038/s41597-020-0389-7) | 单台电器插头端的电压、电流记录及设备元数据 | 提取电气特征，将单个负载分为电阻性与非电阻性。 |

UK-DALE 反映家庭用电活动，TDHA 提供受控开关序列，PLAID 支持单负载特征分析。各案例的任务和评测划分不同，指标应结合对应案例解读。数据版本、标签定义与文件要求见[数据文档](docs/zh-cn/data.md)。

## 项目实现

```mermaid
flowchart LR
    A["功率或电压、电流测量"] --> B["时间对齐与有效性掩码"]
    B --> C["电气特征与历史窗口"]
    C --> D["训练识别模型"]
    D --> E["状态概率或负载类别分数"]
    E --> F["在留出分组或记录上评测"]
```

- **信号处理与特征。** 数据读取接口对齐输入与参考标签，并保留缺失数据掩码。低频流程使用功率水平与变化；高频流程使用相位对齐的电压、电流周期、非有功电流及谐波。PLAID 案例提取 29 项电气特征。
- **模型与训练。** 时间卷积网络（TCN）和门控循环单元（GRU）学习历史测量与设备状态之间的关系，因果窗口在每个预测时刻只使用当前及过去的信号。随机森林处理 PLAID 特征向量。Notebook 展示预处理、模型定义、损失、训练与评测流程。
- **评测与模型复用。** 时序状态识别流程在训练数据上拟合预处理参数，在标定数据上选择阈值，并固定这些参数进行评测。PLAID 使用预设的 0.5 决策阈值。每个入选配置保留全部随机种子（seed）与折次（fold），同时提供拟合参数和模型加载工具。
- **NPU 训练与权重转换。** TDHA 多标签流程在昇腾神经网络处理单元（NPU）上比较波形与谐波两类表示。转换工具生成可由 CPU 加载的权重；已有评测通过 NVIDIA GPU 的 CUDA 环境检查模型在不同采集脚本上的迁移表现。训练硬件、评测硬件与权重格式分别标明。

特征构造、模型配置和评测协议见[方法文档](docs/zh-cn/methods.md)。

## 实验与发现

**平均精确率（AP）**衡量分数对正状态或正类别的排序能力；**召回率（Recall）**表示固定阈值下检出的正例比例；**F1**综合精确率与召回率；**OFF 误报率（FPR）**表示有效关闭状态被误判为开启的比例。下表汇总入选配置的全部已记录 seed／fold。

| 任务与输入 | 主方法 | 结果及其含义 |
|---|---|---|
| [UK-DALE 微波炉状态／10 秒输入](docs/zh-cn/results.md) | 功率特征的因果 TCN，五个 seed | 住宅 2：AP **0.8932**、Recall **95.97%**。识别表现随家庭记录变化。 |
| [UK-DALE 微波炉状态／1 秒输入](docs/zh-cn/results.md) | 因果 TCN，五个 seed | 住宅 2：AP **0.9661**、Recall **94.27%**。在该记录上表现较好，下文另列误报与家庭对照。 |
| [TDHA 微波炉状态／波形输入](docs/zh-cn/results.md) | 相位对齐波形 GRU，两折 × 三个 seed | AP **0.9843**、Recall **80.23%**。排序能力较强，但固定阈值下仍漏检相当一部分开启状态。 |
| [PLAID 电阻性负载分类](docs/zh-cn/results.md) | 按地点分组的五折随机森林 | AP **0.9553**、F1 **0.9281**。电气特征在已记录的地点分组评测中能够区分两类负载。 |
| [TDHA 多插座状态／NPU 训练](docs/zh-cn/results.md) | 波形 GRU 与谐波卷积模型，12 个运行 | CUDA 跨脚本 AP **0.7519** 与 **0.7364**。谐波候选在同一脚本内的优势未延续到其他脚本。 |

**输入分辨率、预测步长和历史长度**描述不同的模型设置。UK-DALE 的 1 秒输入案例每 **10 秒**输出一次预测；TDHA 波形案例读取 **51.2 kHz** 测量，并使用 **51.2 秒**历史上下文。两种 UK-DALE 配置的协议也有差异，因此指标差值不能单独归因于采样分辨率。

### UK-DALE：识别与误报表现随家庭记录变化

1 秒输入的 TCN 在住宅 2 上达到 **AP 0.9661、Recall 94.27%、高功率 OFF 误报率 0.656%**。最后一项指标统计微波炉关闭且家庭总功率至少为 800 W 时的误报，用于检查其他较大负载是否容易被误认为目标电器。

图中比较住宅 1 的前段、后续分区与住宅 2，分别标记为 H1、H2，识别表现随记录变化。两个住宅均已在开发阶段接触过，因此这些结果属于探索性比较；未见家庭中的部署表现仍待检验。

![UK-DALE 1 秒 TCN：住宅 1 与住宅 2 的 AP、召回和高功率 OFF 误报率](results/ukdale-1s/figures/main.png)

### TDHA：同一脚本内的提升未延续到跨脚本测试

两种 NPU 训练模型使用不同的信号表示：**N0-W1** 是波形 GRU 参考方法，**N1-F** 是谐波卷积候选方法。采集脚本规定设备的开关序列；时间留出评测使用同一脚本的后续片段，跨脚本评测使用另一套开关序列。

主要 AP 和 Recall 覆盖两个采集脚本共同支持的 6 个设备类别。N1-F 在 NPU 时间留出评测中表现较好，但在 CUDA 跨脚本评测中 AP 和 Recall 下降。其跨脚本 AP 相对 N0-W1 的差值为 **−0.015522**，95% 配对块置信区间为 **[−0.027810, −0.003263]**，未满足固定的筛选条件。这说明同一脚本内的较高分数不足以证明模型能迁移到其他运行序列。

每种方法展示全部两折、三个 seed 的六个运行。NPU 训练与时间评测、CUDA 跨脚本评测及 CPU 权重转换各有对应范围；NPU 全流程验证状态仍为部分完成。

## 快速开始

```sh
python -m pip install -e .
python -m wattsign results list
python -m wattsign results show tdha-npu
```

以上命令读取已有结果。三本英文 Notebook 包含实现代码和完整训练流程：

| Notebook | 从哪里开始 |
|---|---|
| [低频识别](notebooks/01_low_frequency.ipynb) | 家庭总表功率、微波炉标签与因果 TCN 训练 |
| [高频与 NPU 识别](notebooks/02_high_frequency.ipynb) | TDHA 波形、物理特征、GRU 与多标签流程 |
| [PLAID 分类](notebooks/03_plaid.ipynb) | 单负载特征、分组交叉验证与随机森林训练 |

运行新实验时，配置本地原始数据和新的输出目录，再开启对应执行开关。安装与配置见[快速开始](docs/zh-cn/quickstart.md)，CPU、CUDA 和 NPU 环境见[运行文档](docs/zh-cn/runtime.md)。

## 仓库结构
